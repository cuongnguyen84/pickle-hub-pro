# Current acquisition baseline — 20/11/2026

Read-only GSC/GA4 API reports, using existing service-account access. No
indexing requests or account/configuration writes were made. JSON files contain
aggregate analytics only.

| Source/window | Current | Previous |
|---|---|---|
| GSC, 21/10–17/11 vs 23/09–20/10 | 2,845 clicks; 83,819 impressions; CTR 3.39%; position 7.9 | 2,569 clicks; 68,263 impressions; CTR 3.76%; position 7.4 |

GSC clicks increased 10.7% and impressions 22.8%; CTR declined 0.37 percentage
points and average position worsened by 0.5. GA4 sessions increased 36.9%.
These are descriptive window comparisons, not evidence that any roadmap change
caused the movement. GSC and GA4 use different windows because of reporting lag;
do not directly reconcile their click/session totals.

The reports are global/unfiltered. They do not prove Vietnam-mobile CWV,
journey activation, cohort retention, or human-only traffic. Query/page rankings
and channel mix need separate segmented analysis before choosing SEO work.
Coverage/404 URL dispositions and field CWV remain open.
