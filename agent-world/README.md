# Văn phòng agent ThePickleHub

Ảnh chụp 3D của việc đang chạy, để mở trên máy và bấm từng bàn.

Nguồn hình: skill [cloudai-x/threejs-skills](https://github.com/cloudai-x/threejs-skills) (three.js r186, React Three Fiber 9.8) và bố cục văn phòng trong [lucwj/ai-agent-3d-prompts](https://github.com/lucwj/ai-agent-3d-prompts). Prompt gốc dựng mô phỏng 6 robot giả. Bản này thay bằng đúng việc của ThePickleHub và ghi rõ đây là ảnh chụp, không gọi model.

```sh
cd agent-world
npm install
npm run dev
```

Mở http://localhost:5199. Bấm robot hoặc dòng bên phải.
